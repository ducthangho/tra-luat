WP1038 (CLOUD-SETUP-P2A-EXEC): new `tl agent-creds-exec [--claude] [--gemini] -- <command> …` runs one command with the
Claude token (`CLAUDE_CODE_OAUTH_TOKEN`) and/or the Gemini key (`GEMINI_API_KEY`) from `tl_agent_creds.enc` set only in that
child's environment. The file is downloaded on every call and decrypted in memory with `TL_MASTER_KEY`; nothing is exported,
written to disk or cached. A failed download, a missing or wrong master key, `schema` other than the integer 1 (JSON `true`
too), or a missing or empty requested key returns rc 4 without starting the child; no flag or no command after `--` is rc 2
before any download. The name is resolved with `shutil.which` (rc 127), the child runs from an argv list without a shell, its
exit code is returned as is, and no branch prints a credential value. `AGENT_CREDS_FILEID` now holds the real file id. The
top-level parser rejects abbreviated global flags (`--det`), and the PreToolUse guard denies a subagent `tl` call whose words up
to the command name carry shell expansion (`$'…'`, `${…}`, `$(…)`, braces, globs). New `r1000_*` cases.
