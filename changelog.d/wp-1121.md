WP1121: `doc-claims-check` now flags a citation to a file that was deleted in a committed change when the
citing document is a live document. Before the fix, layer L1 turned every such citation into the advisory
`PATH_DELETED` (rc=0 under `--strict`) whatever the citing document was, so deleting
`ops/RUT_LEASE_PLAT_X8_20260821.md` (cited by `CLAUDE.md`) and
`ops/land/pr909-wp748-r25-land-evidence.yaml` (cited by `docs/adr/0055-tran-loi-goi-codex-len-muoi.md`) passed
the full CI path once committed, and failed only while uncommitted. Now a live document gets the flag
`PATH_DELETED`; a historical document (`_DOC_CLAIMS_HISTORICAL`) gets the new advisory
`PATH_DELETED_IN_HISTORICAL_DOC`. `docs/adr/` stays a live document. The historical test also stops matching
file entries by prefix: an entry ending in `/` is a directory prefix, any other entry must match exactly, so a
file whose name merely starts with a historical file name (the appendix name plus a `.live.md` suffix) is no
longer treated as historical (in L1, L2, L4, L8, L12 and as an L9 pointer source). Measured on base `f4b513d` with full history and `core.abbrev=7`: the 3 existing
`PATH_DELETED` findings all sit in historical documents, so the change adds 0 flags; 0 tracked files change
historical classification. Fragment `wp1121_doc_claims_xoa` builds a real git repository in a temp directory
(`ops/x.md` committed then removed) and checks eight cases across L1 and L9, with preconditions that fail by name
(file in the deleted set, `ops` still a top-level entry, every citing document in the default targets, L9 not
skipped). On the base code it fails cases a, b, c, e, f, g. Not changed (out of scope, debt
`DOC-CLAIMS-XOA-F1-GOC-MAT` on #1121): L1 still drops a token before the deleted-set lookup when its first
segment is no longer a top-level entry (for example `gas-project/Code.gs`, cited at
`references/DEV_TOOLING_GUIDE.md:56`), and for `./` or `../` tokens. Not measured: Windows (pending), and how
many open branches delete a file that a live document still cites.
