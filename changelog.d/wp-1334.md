WP1334 (CODEX-HOME-NGOAI-KHO r2): `tl bootstrap` no longer writes Codex `auth.json` when `CODEX_HOME` is inside a git
repository. New `tl_gws._trong_kho_git(path)` walks from the destination up to the filesystem root on two chains, the path
as given and its `os.path.realpath`, and reports the first ancestor that has a `.git` entry (`lstat`: a directory, a file as
in a worktree or submodule, or a dangling symlink all count). `_bootstrap_agent_creds` then returns `KHÔNG ĐO ĐƯỢC` with
that ancestor and creates no file, no temp file and no directory. The marker file written by `ops/cloud_agent_creds.py`
(`_ghi_dau`) goes through the same check and is also skipped when `tl_gws` cannot be imported. `agent-creds-set --codex`
only reads `auth.json` and is deliberately not gated. Before this change a `CODEX_HOME` under a repository left
`auth.json` as an untracked file one `git add -A` away from a commit (measured 16-11-2026 with fake data).
