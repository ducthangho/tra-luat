WP868: `ops/cai_cong_cu.sh` no longer reads the chosen folder from the installer's stdout. `chon_thu_muc_chay_duoc`
writes it to a private result file (`mktemp`, not exported, removed on exit): `DICH` plus the folder, or `GIU_PATH`
when the bare name already passes. The recipe now runs in a subshell redirected to a file instead of `$( )`, so a
background child that keeps the installer's stdout open no longer stalls the install, and nothing it prints later
is taken as the folder. Recipes that do not call the chooser (pip, `cai_actionlint.sh`) still fall back to the last
stdout line. The `rg` recipes now use the same chooser (WinGet Links / choco on Windows), which also fixes an
installer whose stdout does not end with a newline. New `r868_*` cases (late writer, no trailing newline, last-line
folder, stdout held open, candidate loop) and `wp868_*` mutations, each also killed by a pure-Python shape case.
