- **New subcases inside X4-02**, with every value built from code points:
  - A real deployed endpoint under `$S\rv\COM<U+00C2>\LPT<U+00C2>` (copies of the module under test and S1) must handshake through the real serialized endpoint in every child runtime. Failure token: `ENDPOINT_VALID_PATH_REJECTED[<edition> … parent_codepage= child_codepage=]`.
  - Bases `COM<U+00B9>` and `LPT<U+00B2>` must be rejected with `RequestInvalid` and no import. Failure token: `ENDPOINT_ACCEPTED_INVALID[… reserved-*]`.
  - S1's own path check must agree with all three fixtures; if not, the case is a setup error.
- **Diagnostics added:** `default_codepage` in the parent report and in both child reports; `endpoint_body_nonascii` (the body text as this host decoded it). Both are visible in the retained `endpoint-in.xml`.

## F02 — nested child evidence was deleted before review
- **Where evidence lives:** `$Evid` = `<EvidenceRoot or ScratchRoot>\pxctl-evid-<run>`. It is now created on every run (before, only with `-Counterexamples`). It sits outside `$S` and outside the measured tree.
- **Children run in place:** child scripts, `endpoint-in.xml`, `endpoint-out-N.json`, `wa-*.xml`, `wo-*.json` and the conflict pre-import module are written to `$Evid` and executed from there. The recorded commands are the real durable paths; nothing is copied after execution.
- **Captured output:** each child's full output is written to `c<idx>.output.txt`, whose hash equals `output_sha256`. The capture boundary is stated in the report: this is decoded text (`2>&1 | Out-String`), not the raw child bytes.
- **Report schema `px.evidence.v1`:**
  - `evidence.artifacts[]` holds `{role, child, path, rel, present, bytes, sha256}`.
  - Each `children[]` entry gains `index`, `codepage` and a list of artifact `rel` paths.
  - Each CX record gains `source_dir`, `nested_evidence_root` and `child_index`.
- **CX children (the trap you flagged):** each CX child now gets `-EvidenceRoot "$Evid\CXnn.nested"`. That is a sibling of its measured source copy `$Evid\CXnn` and lies outside the parent's `$S`. The measured-tree check was not relaxed.
- **Checked again after cleanup:** `Test-Evidence` runs after `$S` is removed. It covers the parent's own artifacts and each CX child's nested set, read from its retained report. Any of these makes the run end with rc 2:
  - `EVIDENCE_MISSING_OR_CHANGED[role path]`
  - `EVIDENCE_IN_DELETED_OR_MEASURED_TREE[...]`
  - `EVIDENCE_NESTED_UNRESOLVED[CXnn]`
  - `EVIDENCE_ROLE_MISSING[...]` (checked when rc is 0)
- **CX credit:** a CX is now refused credit (`NESTED_EVIDENCE_NOT_RETAINED[...]`) unless its nested root is in the right place, its own post-cleanup check is `ok`, and every required role is present, with one endpoint report per runtime.
- **Your copy-and-delete negative test:** deleting one artifact should produce `EVIDENCE_MISSING_OR_CHANGED`. Paths in a copy resolve through `rel` against `evidence.dir`. For nested sets, take `nested.dir` relative to the parent's `evidence.dir`.
