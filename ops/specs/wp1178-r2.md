## Acceptance

1. Updater cùng dùng manifest/checker, check mặc định không cài; `Apply` cài thiếu, `Latest` chỉ nâng các công cụ được chọn; không cài trùng nếu đạt phiên bản yêu cầu. Các gói hệ thống lấy bản mới nhất của package manager; không tự nâng major Python/Node mặc định.
2. Windows và Linux/WSL có đường thực thi native. Linux `--user-only` không gọi sudo/apt, kiểm tra tiền điều kiện trước mutation. Cài AGY có kiểm SHA256 release asset; tài liệu nói rõ CLI không được Google hỗ trợ chính thức.
3. Script login chỉ thêm đường dẫn CLI vào PATH của phiên và đặt `TL_REPO`, idempotent; không đọc hay lưu `TL_MASTER_KEY`, không tự bootstrap hay sửa profile. README nêu lệnh opt-in để nối profile, bootstrap theo repo, tiền điều kiện sudo/user-only.
4. Trên ASUS: parser PowerShell, `bash -n` WSL, login smoke tests, updater check mode Windows và WSL thoát 0; `ops/cong_cu.py` và actionlint/ShellCheck canary `DAT`. Ghi rõ bản WSL apply user-only đã đạt, Windows apply còn chưa chạy khi tiến trình đang dùng CLI, VM system scope chưa đo.
5. Reviewer độc lập đọc exact candidate SHA và các file thực tế, kiểm nguy cơ bảo mật, idempotence, compatibility và tài liệu. Mọi finding P0–P2 phải được xử lý rồi review lại exact head.
6. `git diff --check` đạt; CI bắt buộc của PR xanh trên head cuối. Land chỉ khi có authorization bền cho đúng mission/head, review và gate đầy đủ; không deploy.
