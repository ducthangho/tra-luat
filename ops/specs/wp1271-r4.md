## Objectives and API

M1 (ProximaConfig.psm1): export Read-ProximaConfig with mandatory absolute
ConfigPath and RepositoryRoot, without settings discovery, defaults or writes.
M2 (config.example.json): one placeholder-only example of schema below.
M3 (ProximaConfig.Tests.ps1): self-contained focused fixtures and counterexamples,
no new test dependency, real PS5.1 and PS7 executions with positive counts.

Schema: JSON object, schemaVersion integer 1, nonempty string targetId,
mode Local|Remote, absolute basePath. Remote additionally requires absolute
HTTPS connectionUri and nonempty configurationName. Local rejects those remote
fields. Reject unknown fields, wrong types, secret fields and empty values.
Missing config is an error; no implicit Local gateway. Auth remains outside JSON.
ConfigPath must resolve to an existing ordinary file outside RepositoryRoot.
Containment uses normalized absolute paths with directory boundaries and Windows
case-insensitive comparison. Reject any reparse point in either path's ancestors
or config file; do not try to follow ambiguous junctions. Reject relative/rooted
but drive-relative paths, UNC ambiguity and unresolved filesystem paths.
BasePath is validated syntax, not opened; reading must not contact target.
Return only validated properties. Error messages never echo raw JSON or values.
Import and read never create files, HTTP requests, sessions, processes or services.
